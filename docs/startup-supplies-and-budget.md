## Total budget

**Lean launch on $1,000 (DBA route):**

| | Cost |
|---|---|
| DBA, EIN, sales tax certificate, CE-200 | ~$25–120 |
| Insurance deposit | ~$100–175 |
| Outreach setup, first month | ~$150–200 |
| Supply kit (budget vacuum) | ~$400–500 |
| Safety basics | ~$75–100 |
| Printing | ~$25 |
| **Total** | **~$800–1,100** |

**Fully set up in the first 60–120 days, paid for by the first jobs:** add ~$1,500–3,000 (LLC registration and notice if you take that route, full-year insurance and bond, commercial backpack vacuum, shirts, magnets).

**When you hire or take project jobs:** add ~$1,500–3,000 plus payroll and workers' comp (second kit, fiberglass ladder, HEPA vacuum for construction dust, floor machine or extractor rentals).

**Running costs:** ~$80–250/month software and outreach, ~$100–175/month insurance, ~$10–25 per client per month in consumables. Build that into every quote.
